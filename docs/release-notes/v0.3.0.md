**The channelizer bitstream** (`websdr_pfb.bit`, `docs/channelizer.md`):
a polyphase filter bank that splits the whole HF range (0-61.44 MHz) into
30 kHz bins at 60 kS/s, a power line for the full-band waterfall, and a
tuner in the FPGA that turns and decimates 32 users' bins to 12 kS/s.
Receivers are then limited by the CPU, not by the FPGA's 12 channels.

* **Tested on a Web-888 since 2026-10-29** with web888-ng's open driver
  and web888d in bins mode (v0.4.0 and the builds leading to v0.5.0): a
  remote unit with FT8 skimmers on ten bands and web listeners, load
  tests up to 32 listeners with waterfalls, no hang. The bitstream here
  is CI's build of the same FPGA source as the one tested (Vivado 2026.1,
  timing met with the guardband).
* It needs the open driver from this repository (`driver/`, the
  `ZSDR_PFB_*` interface); the stock driver doesn't know its register
  map. web888-ng-os images from v0.2.0 carry both.
* HF and VHF bitstreams: their function is as in v0.2.0, but code they
  share with the channelizer changed (register block, ring writer,
  FIFO), and these builds have not run on hardware. v0.2.0's HF is the
  hardware-tested one; web888-ng-os keeps using it.
* New asset: `ps7_init.tar.gz`, the PS7 initialisation of the block
  design, which web888-ng-os's U-Boot SPL uses as its first stage.

Use it on a unit you can't power-cycle only with the watchdog armed, as in
`docs/hardware-test-plan.md`.
