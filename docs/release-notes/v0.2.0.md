**The first open bitstream that runs on hardware.** v0.1.0 hung the board
on its first register access: the bus reset came from the PS's
FCLK_RESET0_N, which the PS holds while fclk0 is gated, and the stock
kernel leaves fclk0 off. The bus reset now comes from a power-on counter
in the PL (released 128 clocks after the ADC clock PLL first locks).

* **HF, tested on a stock unit (2026-10-28):** loaded at run time through
  devcfg, with the watchdog armed (`docs/hardware-test-plan.md` §0). The
  stock driver reads the signature and DNA, and web888d receives at 48 k
  frames/s with no rate warnings or ADC overloads. It then ran for about an
  hour: FT8 skimmers on eight bands, then FT8, FT4 and WSPR on ten,
  with web users on the waterfall and audio.
* **VHF: not yet tested on hardware.** Simulation and timing only.
* New: liveness bits on EMIO GPIO (PLL lock, clock heartbeats, the reset
  state), which the PS reads without touching the PL's bus
  (`tools/slcr-peek`, `slcr_peek gpio`). They found this bug.

Use it on a unit you can't power-cycle only with the watchdog armed, as in
the test plan.
